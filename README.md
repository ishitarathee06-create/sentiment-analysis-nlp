# Sentiment Analysis Web Application Using NLP

A machine-learning-based web application that classifies English text into three sentiment categories: Positive, Negative, and Neutral.

## Features
- Text input and validation
- Text preprocessing using NLP techniques
- Sentiment prediction using Logistic Regression
- TF-IDF feature extraction
- Confidence score for predictions
- Interactive Gradio interface

## Technologies Used
- Python
- Scikit-learn
- NLTK
- Gradio
- Joblib
